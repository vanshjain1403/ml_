# 🚀 Data Analysis & Core Machine Learning Prerequisites

This repository contains my practical implementations and deep dives into Python for Data Science and Machine Learning. It tracks my progress in data manipulation, numerical computing, exploratory data analysis (EDA), and working with real-world datasets.

---

## 📂 Repository Structure

| File Name | Core Concepts & Libraries Mastered |
| :--- | :--- |
| 📄 **`numpy.ipynb`** | Core NumPy architecture, vectors, and multi-dimensional matrices. |
| 📄 **`Arrays.ipynb`** | Matrix initialization, shapes, memory layouts, and data types. |
| 📄 **`ArrayIndexing&Slicing.ipynb`** | Subsetting, conditional filtering, and fancy indexing tricks. |
| 📄 **`ArrayOperations.ipynb`** | Universal functions (ufuncs), broadcasting rules, and vectorization. |
| 📄 **`Series.ipynb`** | Introduction to Pandas 1D labeled structures and alignment. |
| 📄 **`DataFrames.ipynb`** | 2D tabular structural operations, indexing, and attributes. |
| 📄 **`FindingData.ipynb`** | Row/column selections using `.loc`, `.iloc`, and boolean masking. |
| 📄 **`MissingData.ipynb`** | Handling null values using drop methods, imputations, and fills. |
| 📄 **`GroupBy&Aggregation.ipynb`** | Split-Apply-Combine pipelines for statistical breakdowns. |
| 📄 **`MergingJoiningConcatenation.ipynb`** | Relational algebra, database-style joins, and concatenations. |
| 📄 **`PivotTables.ipynb`** | Advanced data reshaping, multi-indexing, and cross-tabulations. |
| 📄 **`Operations.ipynb`** | Unique values, value counts, map/apply custom functions. |
| 📄 **`apidatafetching.ipynb`** | Working with REST APIs, handling requests, and JSON parsing. |
| 📄 **`onejson.ipynb`** | Loading, normalizing, and structured handling of JSON datasets. |
| 📄 **`anime.ipynb`** & **`anime.csv`** | Full End-to-End EDA on real-world multi-featured anime metadata. |
| 📄 **`exersises.ipynb`** | Problem-solving notebooks to cement analysis and logic skills. |
| 📄 **`one.ipynb`** | Scratchpad for algorithmic execution and syntax checking. |
